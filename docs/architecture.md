## Принципы

- **Локальность прежде всего.** Room — источник истины. Всё, что делает мастер, записывается локально; облако — это бэкап и точка AI-генерации.
- **AI — только текст.** Фотографии не отправляются в AI. Это дешевле, быстрее и приватнее.
- **Структурированный вывод AI.** AI возвращает JSON `{work_performed, materials, notes}`, из которого приложение собирает PDF. Произвольный HTML/PDF от AI не генерируется.
- **Абстракция AI.** Серверная часть использует интерфейс `AIProvider`; смена провайдера = новая реализация, без переписывания логики.
- **Простота.** Один разработчик должен сопровождать проект. Никаких микросервисов.

## Слои Android-приложения

| Слой | Ответственность |
|---|---|
| UI | Jetpack Compose, экраны: реквизиты, список работ, новая работа, редактирование отчёта, просмотр PDF |
| ViewModel / UseCase | бизнес-логика экрана, состояния |
| Repository | единая точка доступа к данным (Room + сеть) |
| Room | локальные таблицы и DAO |
| SyncService | фоновая синхронизация при появлении сети |
| SpeechRecognizer | распознавание голоса на устройстве |
| PDFGenerator | сборка PDF из JSON |
| SupabaseClient | REST + Storage + edge-функции |

## Статусы и синхронизация

Каждый элемент (работа, фото, отчёт, реквизиты) имеет статус:

- `LOCAL` — сохранено на устройстве
- `UPLOADING` — загружается
- `SYNCED` — готово (в облаке)

Синхронизация запускается при появлении сети и идёт в порядке: работа → фото → реквизиты → отчёт.

## AI-генерация

1. Мастер нажимает «Создать отчёт».
2. Если сети нет — предлагается ручной режим; генерация помечается «ожидает сети».
3. Клиент вызывает edge-функцию `generate-report` с текстом описания и реквизитами.
4. Edge-функция формирует промпт, вызывает `AIProvider`, парсит JSON.
5. Результат возвращается клиенту для редактирования.

## Обработка ошибок

- AI-ошибка: «Повторить» + предложение ручного режима.
- Ошибка синхронизации: статус остаётся `LOCAL`, повтор при следующей сети.
- Пользователь всегда видит статус сохранения.

## Развёртывание

- Android: APK/AAB через Android Studio / Gradle.
- Supabase: миграции БД + edge-функция `generate-report` (см. `deployment.md`).
