# Продукт: «ОтчётМастер» (рабочее название)

Мобильное приложение для индивидуальных специалистов, выполняющих выездные работы.

## Проблема

Специалист после выполнения работы тратит время на составление профессионального отчёта для клиента: описывает работы, собирает фото, оформляет документ. Это рутинно, медленно и неудобно делать «на объекте» одной рукой.

## Решение

Приложение позволяет быстро зафиксировать выполненную работу (фото + голосовое/текстовое описание) и с помощью AI превратить это в структурированный профессиональный отчёт и PDF для клиента.

## Целевой пользователь MVP

- **Кто:** мастер по ремонту и отделке (первая версия — только для него)
- **Где:** Россия и СНГ
- **Окружение:** объект клиента, телефон в одной руке, часто без стабильного интернета
- **Уровень подготовки:** минимальный, интерфейс без лишних элементов

## Ценность для пользователя

Быстро создать и отправить профессиональный отчёт после завершённой работы, не думая о форматировании.

## MVP-сценарий

1. Первый запуск — один раз заполняются реквизиты мастера (имя, телефон, город)
2. «Новая работа» → дата, адрес, имя клиента, телефон
3. Обязательные фотографии (без подписей)
4. Описание работ: голос (распознавание на устройстве) или текст
5. Материалы (простые строки: название, количество)
6. «Создать отчёт»:
   - если есть сеть — AI структурирует текст в отчёт (JSON)
   - если сети нет — доступен ручной режим без AI
7. Редактирование отчёта
8. Создание PDF (на устройстве)
9. Отправка PDF клиенту
10. Работа сохраняется в историю

## Ключевые продуктовые решения

| Решение | Значение |
|---|---|
| Платформа | Android (Kotlin + Jetpack Compose) |
| Язык интерфейса | русский |
| Язык отчёта | русский (совпадает с интерфейсом) |
| Вход | нет; анонимная сессия Supabase, один телефон |
| Офлайн | максимальный: сбор данных офлайн, AI-генерация при появлении сети |
| Ручной режим | есть, без AI |
| AI и фото | AI получает только текст, фото не отправляются в AI |
| Отчёт | структурированный JSON → PDF на устройстве |
| PDF | создаётся на устройстве |
| Отправка клиенту | только PDF |
| Хранение фото | в облаке, до удаления мастером |
| История работ | есть |
| Счёт/база клиентов/гарантия/подписи | вне MVP |

## Вне MVP (потенциально позже)

- Счета и расчёт стоимости
- База клиентов и история по клиенту
- Гарантия в отчёте
- Подписи к фотографиям
- Мультиплатформа (iOS)
- Монетизация (бесплатный лимит / разовая покупка / подписка / пакеты)
- Команды, роли, CRM, ERP, склад, бухгалтерия — только по явному решению

## Компромиссы MVP (осознанные)

- Данные привязаны к одному телефону: при потере устройства история не восстанавливается (нет входа). Принято для упрощения MVP.
- Отчёт только на русском языке.
- Отправка только через PDF (без email/мессенджеров из приложения).

## Метрики успеха MVP (проверяем после запуска)

- Мастер создал первый отчёт за N минут от первого использования
- Доля работ, завершённых созданием PDF и отправкой
- Частота использования (работ в неделю)
- Обратная связь о качестве отчётов от клиентов мастера
