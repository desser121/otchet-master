# ADR-003: Хранение — локально (Room) + облако (Supabase Storage) для фото

Статус: **Принято** (продуктовое интервью, блоки 4, 9)

## Контекст

Мастер работает на объекте без стабильного интернета. Нужно: не терять данные при потере сети, сохранять фото в облаке до удаления мастером, обеспечивать историю работ.

## Решения в рамках этого ADR

- **Локальная база Room — источник истины.** Всё сначала записывается на устройство. Облако — бэкап и точка AI-генерации.
- **Фото хранятся в облаке до удаления мастером** (блок 4).
- **Фоновая синхронизация** при появлении сети: работа → фото → отчёт → реквизиты (блок 9).
- **Привязка к телефону:** без входа; при потере устройства данные не восстанавливаются (осознанный компромисс MVP).

## Альтернативы, отклонённые

- Хранить только в облаке, без локальной копии — несовместимо с офлайном.
- Удалять фото после генерации отчёта — противоречит решению «хранить до удаления мастером».
- Пин-код/вход для переноса данных — отложено (вне MVP).

## Последствия

- Локальное хранилище — обязательное требование к клиенту.
- Статусы синхронизации (LOCAL/UPLOADING/SYNCED) видны пользователю.
- Затраты на Storage растут с объёмом фото (bucket приватный, EXIF удаляется).
