# ADR-001: Мобильный стек — нативный Android (Kotlin + Jetpack Compose)

Статус: **Принято** (продуктовое интервью, блок 7)

## Контекст

MVP — приложение для мастера по ремонту/отделке в РФ/СНГ. Требования: сильный офлайн, распознавание речи на устройстве, генерация PDF на устройстве, единственный разработчик без глубокого опыта, низкая стоимость.

## Рассматриваемые варианты

1. **Нативный Android (Kotlin + Jetpack Compose)**
   - Плюсы: лучшая поддержка офлайна (Room), распознавание речи (SpeechRecognizer), PDF — нативные механизмы; максимум возможностей на одном устройстве.
   - Минусы: не переносится на iOS без переписывания.
2. **Flutter + Supabase**
   - Плюсы: один код на Android и iOS.
   - Минусы: офлайн-хранилище, распознавание речи и PDF настраивать сложнее; для MVP с одним Android — оверхед.
3. **React Native**
   - Отклонено: худший баланс для нативного офлайна и речи.

## Решение

Нативный Android: Kotlin + Jetpack Compose. Room — локальная БД (источник истины). Supabase в качестве бэкенда.

## Последствия

- Android — единственная платформа MVP.
- iOS потребует отдельной разработки позже.
- Офлайн и голос — нативные, дешёвые, бесплатные.
