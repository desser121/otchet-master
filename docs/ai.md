# AI

## Место AI в продукте

AI — не рекламная функция, а механизм превращения неструктурированного текста мастера в структурированный отчёт. Он скрыт за серверной прослойкой и не владеет данными: пользователь всегда видит и правит результат.

## Пайплайн

```
Текст описания + реквизиты (мастер)
        │
        ▼
Edge-функция generate-report
        │
        ├── формирование промпта
        ├── вызов AIProvider
        ├── валидация JSON
        ▼
Структурированный отчёт
{ work_performed, materials, notes }
        │
        ▼
Редактирование пользователем
        │
        ▼
PDF на устройстве
```

Фотографии в AI **не отправляются** (решение блока 6). Это снижает стоимость, latency и приватность-риски.

## Принципы

- **Структурированный вывод.** AI возвращает строгий JSON, никакого произвольного HTML/PDF.
- **Абстракция провайдера.** Интерфейс `AIProvider`:
  ```ts
  interface AIProvider {
    generateReport(input: ReportInput): Promise<ReportJSON>
  }
  ```
  Реализация зависит от провайдера (промпт, формат запроса). Смена провайдера = новая реализация.
- **Провайдер выбирается тестом.** Кандидаты: YandexGPT, GigaChat, OpenAI. Критерии: качество русского текста, стоимость запроса, способ оплаты, юрисдикция данных. Решение фиксируется ADR-004 после теста.
- **Без повторных запросов без необходимости.** Промпт однократный; повторный запрос — только по явному действию («Повторить»).

## Промпт (черновик)

Роль: структурировать черновое описание работы в отчёт.

Вход: `description`, `materials_hint`, `master_name`, `client_name`, `date`.

Правила для модели:
- переписать описание профессионально и грамотно;
- разбить на логичные пункты;
- не выдумывать факты, которых нет в описании (запрет галлюцинаций);
- материалы — перечислить из подсказки, если пусто — оставить пустым массивом;
- ответ — строго JSON без пояснений.

## Расходы и ограничения (мониторинг)

| Параметр | Что учитываем |
|---|---|
| Стоимость запроса | зависит от провайдера и длины текста |
| Токены | ограничение длины `description` на входе |
| Latency | целевое 10–15 с; таймаут в edge-функции |
| Ошибки | AI_ERROR / AI_TIMEOUT / AI_INVALID_RESPONSE |
| Повторные запросы | только по кнопке «Повторить» |

## Обработка ошибок и мусора

- Таймаут → `AI_TIMEOUT` → клиент: «Повторить» + ручной режим.
- Невалидный JSON → `AI_INVALID_RESPONSE` → ретрай один раз, затем ручной режим.
- Галлюцинации ограничиваются промптом («не выдумывай») и тем, что результат всегда редактируется пользователем.

## Приватность

- В AI отправляется только текст описания и реквизиты (имя, город, дата, имя клиента).
- Фото, адрес и телефоны в AI не отправляются.
- Логи не содержат персональные данные.
